# Evidence

One folder per phase, generated by `node scripts/evidence.mjs <N>` at the commit that gets tag `phase-N`:

- `phase-N/summary.md`: test counts, headless scenarios run twice (determinism), machine info, commit.
- `phase-N/test-report.txt`: full `npm test` output.
- `phase-N/scenarios/<case>/`: command and JSONL output for each `tests/scenarios/<case>`.
- Screenshots / clips for things only visible in the game go next to them, each named after the criterion it proves.

Requirement → criterion → evidence tables are in [`docs/notes/phase-N.md`](../notes/phase-1.md). To re-check: `git checkout phase-N && npm ci && node scripts/evidence.mjs N`.
